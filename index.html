Help Guide

Design, simulate, and analyse emergency evacuation scenarios.

Design Your Map

Use the Edit Panel to shape your environment. Select a brush and tile type to paint the grid.

  • ⚑ Goal: The safe zone agents must reach.
  • ⬤ Spawn: Where agents appear in the simulation.
  • ◼ Wall: Permanent walls that block movement.
  • ✷ Fire: The origin point where fire begins to spread.

Use Clear to reset or Upload/Download to save JSON files.

Run Simulations

Toggle the Mode Button in the top-right corner to switch modes.

  • Validation: Requires at least one Goal and one Spawn zone.
  • Parameters: Adjust Speed, Fire Spread, and Agent Count.
  • Live Data: View stats in the Statistics Panel during a run.

Pro Tips

  • Place fire near doorways to test choke points.
  • Agents dynamically reroute as fire blocks paths.
  • Save complex layouts using the JSON feature.
